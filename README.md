# OpenQuery for calc
Free, open-source data transformation pipeline for LibreOffice Calc, inspired by Power Query.
This extension was written entirely by Claude (Anthropic) based on specifications
and feedback from the maintainer (joaswerk). The maintainer cannot read the code
and has verified it only by testing it in LibreOffice Calc.
It is provided "as is", without warranty (see LICENSE). Use at your own risk and
back up your files before use. Bug reports and code reviews are welcome.

## About the author
I'm joa, a long-time, frequent Excel user. For years I believed Excel was
irreplaceable for my work, mainly because LibreOffice Calc had nothing comparable
to Power Query. I'm not a programmer and I can't read the code myself, so I built
this extension together with Claude (Anthropic), which wrote the code based on my
requirements and feedback. I tested it on my own real-world data tasks, and I'm
sharing it in the hope that it helps others who want to switch from Excel to
LibreOffice without losing their data-transformation workflow.
